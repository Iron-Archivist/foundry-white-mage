# White Mage for Foundry VTT (dnd5e)

A Foundry VTT module that adds the **White Mage**, a Final Fantasy job converted to D&D 5e as a homebrew class by **ArchiverButcher** ([@ArchiverButcher](https://twitter.com/ArchiverButcher)), to the dnd5e system.

All class text and design belong to the original author. This module only converts that content into Foundry data. Final Fantasy and White Mage belong to Square Enix. Spell links point to the dnd5e system's SRD compendium (CC-BY-4.0).

## Install

In Foundry go to **Add-on Modules → Install Module** and paste this manifest URL:

```
https://github.com/Iron-Archivist/foundry-white-mage/releases/latest/download/module.json
```

Requirements: Foundry v13 and dnd5e 5.x (tested on 13.350 with dnd5e 5.3.3).

## Contents

- **White Mage class:** d6 hit die, Wisdom and Charisma saves, skill choices, starting equipment, full-caster spellcasting (Wisdom, prepared spells), cantrips-known scale and ASIs. Features at 1, 3, 5, 7, 11, 17 and 20.
- **Orders:** Turmoil, Serenity, Sacrifice and the Lily. Each has features at 2, 6, 10 and 14 and grants its SRD Order spells as always prepared.
- **Homebrew spells:** Glare, Aero and Stone's Endurance.
- **White Mage spell list:** registered with dnd5e, so it shows up in spell list filters. Spells outside the SRD are listed by name only.

## White Mana

*White Mana* is a feature whose uses are your current mana (max = proficiency bonus). It starts empty and empties on a long rest. Click **Gain White Mana** after a qualifying spell. Any feature that costs White Mana deducts it from this pool automatically: a small script links each feature to the pool when the feature is added to a character. For Order of the Lily, the same pool tracks petals. Orison has its own pool, half your Wisdom modifier, rising to your full modifier at 11th level.

Not automated (the feature text says so where it applies): Afflatus Liturgy's short-rest recharge at 20th level, the hit point juggling of Weight of Sacrifice, and how healing splits.

## Building

The compendium packs are generated by `build/gen.py` (document data) and `build/pack.mjs` (writes the LevelDB packs, using Foundry's bundled `classic-level`):

```
python3 build/gen.py build/srd.json build/docs.json
node build/pack.mjs build/docs.json packs   # Foundry must not have the packs open
```
